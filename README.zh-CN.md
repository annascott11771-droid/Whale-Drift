# 鲸跃深潮 / Whale Drift

**一款使用 Godot 4.7 制作的 2D 深海无尽跑酷。**

> 本仓库只包含**游戏源码和测试**。贴图、音频、字体和图标都不包含在仓库中；要构建可玩版本，请按 [`godot/assets/ASSETS.md`](godot/assets/ASSETS.md) 补齐素材。

## 简介

《鲸跃深潮》是一款 2D 深海无尽跑酷。操控鲸鱼穿过微光珊瑚海、暮色峡谷与幽蓝深渊，在尖刺、海胆和洋流之间寻找缝隙，收集珍珠、气泡护盾与加速。六档难度、手柄支持、分辨率设置，速度缓慢提升；没有跳跃键，只有流动、节奏和一次深呼吸。使用 Godot 4.7.2 制作。

## 特性

- 无限横向地图与自由上下游动
- 尖刺与门缝使用收窄多边形，礁石/水母/海胆使用缩小的椭圆碰撞
- 珍珠、可叠加气泡、洋流加速、冲刺（全程无敌）与检查点
- **6 点血量，显示为 3 颗心**；一次受击扣半颗心，爱心按 1/4 档绘制，血条与数值永远一致
- **气泡叠加**：每层抵挡半次伤害并消耗一层，最多 6 层，带可见护罩
- **天赋商店与珍珠经济**（见下）：护盾时长 / 冲刺距离 / 珍珠磁铁永久升级
- 六档难度：浮光悠游 到 海沟寂灭
- 缓慢提速，支持 30–240 FPS、分辨率与显示模式
- 帧率数字读取引擎实测值；只有上限低于屏幕刷新率时才关闭垂直同步
- 键盘、鼠标、标准手柄和触摸操作
- Android 支持：全屏沉浸式、ETC2/ASTC、返回键与切后台处理
- 平板布局：1280×720 设计画布向外扩展而不是加黑边，内容居中
- 英文 / 中文界面，可在 **设置 → 语言** 或按 **L** 切换
- 本地 JSON 存档与自动检查点

## 操作

### 血量与气泡

血条一共 **6 点**，显示为 **3 颗心**（每颗心 2 点），爱心按 1/4 档绘制
（满 / 3⁄4 / 半 / 1⁄4 / 空）。

- 正常受击扣 **1 点**，即 **半颗心**
- 气泡每层抵挡 **半次伤害**，用掉一层
- 已经有气泡时再吃到气泡会**叠一层**
- 最多 **6 层**，绕在鲸鱼周围，HUD 显示 `气泡 ×N`
- 气泡有持续时间，时间到会消散，再吃一个会刷新

### 天赋商店与经济

`GlobalData.gd` 是 Autoload 单例，负责钱包、三个天赋等级和存档
（`user://save_data.cfg`，用 `ConfigFile` 读写）。

| 天赋 | 效果 | 升级价格 |
|---|---|---|
| 护盾时长 | 3.0 秒 → 5.0 秒 | 50 / 120 / 250 / 500 |
| 冲刺距离 | 100 → 180 | 60 / 140 / 280 / 560 |
| 珍珠磁铁 | 0 → 200 像素 | 80 / 180 / 360 / 720 |

单局结算：

```text
距离 = floor(距离 / 100)
收集 = min(本局吃到珍珠, 12)
积分 = 分数 >= 10 万时 1 + floor((分数-10万)/5万)，最多 10
合计 = min(距离 + 收集 + 积分, 50)
```

一局 1200 米大约 24 颗，第一级天赋需要 2~3 局。

`ShopUI.tscn` 负责面板绘制与交互（同时支持鼠标和触摸，工程内已关闭触摸转鼠标）。
珍珠不足时整行红闪，满级按钮变灰显示 **MAX**。

## 构建

需要 **Godot 4.7.2**、Windows x86_64 导出模板，以及 [`godot/assets/ASSETS.md`](godot/assets/ASSETS.md) 中列出的素材。

1. 将所需贴图、音频和字体放入 `godot/assets/`
2. 用 Godot 打开 `godot/project.godot`
3. **项目 → 导出 → Windows Desktop**，启用 **Embed PCK** 后导出

Android 需要安装 Android 构建模板和 SDK，然后使用 Android 预设导出。工程已设置为横屏、沉浸式和 ETC2/ASTC 纹理。

## 测试

工程自带三个自检场景：

```bash
godot --path godot --rendering-driver opengl3 res://TouchTest.tscn
godot --path godot --rendering-driver opengl3 res://DesktopTest.tscn
godot --path godot --rendering-driver opengl3 res://Bench.tscn
```

- `TouchTest`：打开 4:3 窗口，注入真实触摸事件，检查菜单、设置、语言行、拖动游动、屏幕按钮、重开重置、冲刺无敌和碰撞
- `DesktopTest`：检查窗口模式、分辨率切换、帧率上限、鼠标点击路径和设置行
- `Bench`：输出平均 / p95 / 最差帧时间

## 存档
